# 035 中英文字級與字型載入

範圍：活動標題、資訊與英文版的閱讀層級。

證據：style.css 使用本機 Noto Serif 與 Sans，字型檔約 170 KB 與 127 KB，均設定 font-display:swap。build.mjs 新版預載 Sans，符合首屏資訊與操作的用途。舊樣式存在多段覆寫，手機內文曾提高至 20 至 22px，若直接沿用可能增加首屏高度。

建議：活動名與日期建立清楚層級，中文內文維持可讀字級，縮短文字比壓小字更有效。英文行長與中文分開檢查，避免主標強制換行後擠壓日期與操作。只預載首屏確實使用的字型，保留系統備援與文字先顯示的行為。新增文案需檢查本機字型是否涵蓋所需字元。

未知：字型對 LCP 與版面位移的實際影響尚未量測。應在手機視窗、慢速網路及字型尚未完成載入時檢查，不能只依檔案大小判定效能。
