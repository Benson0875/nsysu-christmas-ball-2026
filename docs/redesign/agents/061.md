# 061 手機五秒辨識與任務測試

範圍：手機首次到站是否能理解活動並找到下一步。

程式證據：dist/index.html 先呈現中山聖誕舞會、平安夜主標、日期時間地點、各系學生資格、500／600 元票價及報名入口。700px 以下 CSS 將插畫移至資訊後方。這有利於掃讀，但程式順序無法證明學生真的被吸引。

真人腳本：給受測學生看手機首屏五秒後遮住，請他描述活動、記得的時間地點與想參加或猶豫的原因。再開啟頁面，請他找票價並前往報名，記錄是否成功、時間與卡點。使用中立問題，不提示答案，不代替受測者操作。

未知：尚無真人結果與參加意願基準。53 項自動測試只能支持操作與基本品質，不能宣稱提高吸引力或報名率。
