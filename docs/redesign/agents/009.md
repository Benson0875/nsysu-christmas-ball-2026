# 009 節目規劃與確認卡司的界線

範圍：學生能否理解活動內容，同時辨認哪些仍在規劃。

證據：`src/event.mjs` 的 eveningIntro、programNote 已標示預計與目前規劃。`docs/redesign/FACTS.md` 指出提案第 3 頁包含迎賓、表演、口播、遊戲、抽獎、合舞與合照，沒有確認卡司或分段時間。

建議：首頁以「當晚規劃」介紹表演、遊戲與合舞，附近保留一次清楚的規劃標示。節目頁依環節呈現具體內容，刪除「把目光交給舞台」「把平安夜留給彼此」等無資訊句。尚無資料時，不出現藝人頭像、倒數公布卡司或虛構抽獎品。活動時間與報到時間分開說明。

未知：正式演出者、獎品、各環節時間尚未確認。節目是否足以提高參加意願，仍須真實學生測試。
