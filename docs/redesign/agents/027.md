# 027 從活動頁提升到參加流程

範圍：把 Felix Rieseberg 的高度方法用在活動網站，將工作目標從完成頁面提升到協助學生做出參加決定。

來源：作者原文 https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/ 。原文主張追問任務背後的結果，並建立可驗證的工作流程。

具體流程：先用首屏交代日期、地點與活動內容，再讓學生比較票種與優惠，看到付款成立條件，最後前往正式報名表。把票價查看、報名外連與可取得的實際付款資料分開觀察。找真實學生完成找票價、判斷資格、找報名入口三個任務，記錄卡住的位置後修改。

限制：這是方法轉用，不能證明新版會提高報名。外連點擊不等於表單送出，表單送出也不等於完成繳費。未取得後台資料時，要保留這些觀測缺口，不能補造轉換率。
