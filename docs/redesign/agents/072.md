# 072 鍵盤焦點與標題語意

範圍：檢查新版建置模板、焦點樣式與現有無障礙測試，未使用共用瀏覽器。

證據：每頁有單一 main 與指向 #main 的跳轉連結。焦點連結、按鈕及 summary 使用 3px 暖金外框，跳轉連結聚焦時顯示。導覽有 aria-current，手機按鈕同步 aria-expanded。測試要求每頁一個 h1，涵蓋 Escape 回到選單按鈕，以及 FAQ 與插畫 disclosure 的 Enter 操作，並使用 axe 檢查。

建議：維持原生連結、button 與 details 語意。補一個鍵盤 Tab 到跳轉連結後啟用的測試，確認焦點或後續 Tab 起點確實進入主要內容。main 目前沒有 tabindex，不能只憑錨點存在宣稱所有瀏覽器的跳轉焦點行為一致。

未知：本次未執行螢幕閱讀器或跨瀏覽器人工鍵盤測試。現有靜態檢查未發現必須阻擋交付的語意問題，axe 通過也不能取代真人操作驗證。
