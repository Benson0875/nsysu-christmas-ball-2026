# 005 非籌辦系所學生的參加資格

範圍：學生會不會把七系聯合誤解為只有七系能參加。

證據：src/event.mjs 的主辦名稱使用七系聯合，audience 則明列國立中山大學各科系學生。首頁介紹與參加資訊 FAQ 也確認其他系所可參加。docs/SOURCES.md 將此資格追溯至品牌合作提案第 3 頁。

建議：首屏活動資訊直接加入「中山各系學生皆可參加」，與日期、地點並列。主辦單位另列於頁尾，避免讀者從主辦名稱推論入場限制。保留參加資訊頁的完整資格與 FAQ。

未知：外校學生、教職員、校友能否參加，現有資料未確認。不能把「各科系」擴寫為「所有人」或「不限學校」。若正式開放外校，需同步修改報名規則與兩種語言。

驗證：請非籌辦系所學生看首屏五秒後，詢問自己能否參加，記錄原話與判斷依據。此建議尚未經真人測試。
