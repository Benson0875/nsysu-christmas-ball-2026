# 006 揪朋友與分享

範圍：協助已感興趣的學生把活動資訊傳給朋友。

證據：src/event.mjs 有朋友參加的描述與正式 siteURL，registrationURL 為空。scripts/build.mjs 已有分享用 OG 標題、描述和圖片，但 public/app.js 沒有分享操作。現有畫面無法證明學生是否需要揪伴。

建議：在參加資訊旁提供「分享給朋友」，使用裝置原生分享。未支援時改為複製正式活動網址並顯示完成訊息。分享內容包含活動名、12 月 24 日、18:00 至 21:00、福容大飯店及報名狀態。不要把取消分享視為成功，不蒐集朋友聯絡資訊，不以空白報名網址分享。

未知：揪伴是否提高報名率、學生偏好的分享管道。需真人任務測試與上線後分享操作紀錄，不能由按鈕點擊直接推定成功邀人。
