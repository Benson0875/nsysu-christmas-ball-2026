# 發布前檢查

候選分支 redesign/fairytale-editorial，基底 main，版本 1.1.0.0。

此次包含第一輪尚未提交的完整改版，以及使用者指定的第二輪視覺與資訊調整。無伺服器端資料庫或付款實作，沿用公開 Google 表單及官方 IG。

原始碼檢查：外部連結限 HTTPS，品牌名稱與檔名驗證保留，未新增使用者輸入或任意 HTML 來源。報名、優惠及預估人數與已確認資料一致。沒有發布私人提案、憑證、表單回覆或聯絡訊息。

介面檢查：首頁簡化後保留日期地點和報名，優惠完整下移。移除分享橫列與首頁插畫展開。活動頁頂端顯示三聯插畫，遮罩內沒有日期文字。照片使用輕量 IntersectionObserver 入場及 CSS 懸停，支援減少動態。內容預設可見，不因腳本失敗而消失。
