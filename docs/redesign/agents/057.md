# 057 正式中文頁面文案檢查

範圍：以 HTMLParser 擷取 dist 根目錄四個中文頁面的可見文字，排除 head、script、style，並解碼 HTML 實體。

結果：未找到中文或英文分號，也未找到使用者列出的四類禁用句。未出現「不是……而是……」「不只是……更是……」對比套語。FAQ 的「不是主辦七系，也能報名嗎？」是實際資格問題，保留合理。

可刪內容：首頁「入口合照、朋友聊天，這些是去年參加者的活動照片。」與各圖年份說明重複，可刪除。節目頁「節目安排包含現場遊戲、抽獎與合舞。」重複該段標題，可省略。

未知：自然度屬編輯判斷，目前沒有真人閱讀測試，掃描通過不能證明提升參加意願。
