# 018 合作品牌名單與空白狀態

範圍：沒有確認品牌時，贊助頁如何保持可信且有用途。

證據：src/event.mjs 的 sponsors 為空陣列。scripts/build.mjs 只在有品牌資料時產生 Logo 卡片，但空白狀態仍使用「合作品牌將陸續公布」及感謝支持的文字，容易讓讀者以為已有合作正在確認。

建議：未確認品牌時不展示假 Logo、空白卡片或品牌數量。頁面以「品牌合作」為題，直接介紹學生受眾、企劃預估與可洽談曝光項目，提供已確認的官方聯絡入口。只有正式授權後才刊登名稱、Logo、介紹及官方連結，並檢查圖片替代文字。

未知：目前沒有品牌授權檔案、確認名單與公布日期。「將陸續公布」也屬未有依據的承諾，應刪除。正式報名與 Instagram 是後續新增來源，不能沿用早期盤點中的缺少連結結論。
