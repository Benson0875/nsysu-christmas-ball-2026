# 004 學生的票價與報名疑慮

範圍：首次訪客如何判斷花費與報名狀態。

證據：src/event.mjs 的 registrationURL 為 null，費用與報名期限尚無確認資料。scripts/build.mjs 已避免生成虛假的報名按鈕，但首頁仍需進入參加資訊才能理解缺少哪些內容。docs/SOURCES.md 同樣列明票價與表單缺口。

建議：首屏直接顯示已確認日期、時間與地點，旁邊保留「報名尚未開放」狀態。主要操作使用「查看參加資訊」，不得寫「立即報名」。參加頁將費用與報名方式集中呈現，避免在多段文字重複提醒。正式網址加入後，狀態、首頁按鈕與常見問題須同步切換。

未知：票價、報名期限、表單網址與報名完成追蹤方式。是否因價格而流失需真人測試與數據，不能從程式碼判定。
