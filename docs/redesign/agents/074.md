# 074 字型子集與載入檢查

範圍：新版字型是否涵蓋新增中文與標點，及後續維護風險。

證據：scripts/refresh-fonts.py 會收集 src/event.mjs 與 scripts/build.mjs 內所有 U+0080 至 U+FFFF 字元，加上 ASCII 與指定符號，再下載 Google Fonts WOFF2。這已涵蓋全形逗號與問號。file 確認兩檔皆為 WOFF2，Sans 約 139 KB、Serif 約 96 KB。CSS 使用 font-display:swap 與本機後備字型，頁面預載 Sans。截圖與測試等待 document.fonts.ready。

建議：每次新增文案或品牌名稱後重跑子集更新，特別是直接寫在新檔案的文字。Serif 目前下載固定 500 字重，CSS 卻宣告 400 至 700，可縮成 500 以符合實檔。

未知：未逐字比對 cmap，也未量測慢網路 CLS。未包含補充平面字元，未來罕見姓名或 emoji 仍依後備字型顯示。
