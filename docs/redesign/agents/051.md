# 051 贊助標題與簡介文案

範圍：檢查 `src/event.mjs` 的首頁合作橫幅、品牌頁標題與簡介。

證據：目前以「讓學生在活動中認識你的品牌」交代合作目的，簡介列出學生籌辦、參加對象，以及網站、Instagram、現場三個管道。已刪除空泛的感謝、支持與回憶描述，沒有保證品牌觸及量。曝光位置與次數也明列由雙方確認。

建議：保留首頁合作標題、簡介與「私訊洽談贊助」。品牌頁標題「把品牌帶進學生的平安夜」仍稍抽象，可改成「接觸中山學生的合作方式」，下方直接接三類合作項目。若保留原標題，也應維持具體簡介緊鄰，不再增加情緒性段落。

未知：品牌窗口是否認為資料足以洽談，尚無真人訪談。標題修改是編輯建議，不能宣稱提高合作意願。
