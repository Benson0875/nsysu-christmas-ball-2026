# 044 導覽與頁尾層級

範圍：學生主要動線、品牌入口與頁尾資訊分工。

證據：新版 scripts/build.mjs 保留首頁、當晚活動、票價與報名、品牌合作四頁。首屏以金色報名按鈕搭配票價連結，合作資訊位於首頁後段。品牌頁透過官方 Instagram 聯絡。頁尾提供日期、時間、飯店與官方 Instagram，不重複整份導覽。

建議：維持首頁報名的主要視覺地位，品牌合作使用導覽入口與後段獨立區塊。手機選單保留明確的「票價與報名」，避免只用圖示。頁尾的 Instagram 提供共同聯絡管道，品牌頁另保留「私訊洽談贊助」以說明用途。不要加入沒有正式資料的下載提案按鈕。

未知：目前只完成程式與樣式閱讀，尚無真人導覽測試。需檢查 900px 斷點、長英文導覽與鍵盤開關選單，確認沒有遮擋主要入口。頁尾回頁首連結實際指向主要內容，名稱與目的仍可對齊。
