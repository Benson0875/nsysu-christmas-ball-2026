# 066 手機選單操作

範圍：選單鍵盤、Escape、外部點擊與斷點行為。

證據：public/app.js 會同步 aria-expanded 與按鈕名稱，點擊導覽連結、頁首之外或 Escape 都會收起選單。Escape 另將焦點返回按鈕。public/style.css 只在 700px 以下隱藏導覽並顯示選單按鈕，無 JavaScript 時維持導覽可見。scripts/build.mjs 提供 aria-controls 與清楚按鈕標示。

建議：維持非模態展開式導覽，不需套用對話框焦點鎖定。瀏覽器驗證 Tab 可依序到所有連結，Escape 收合後焦點返回切換鈕，選單收合不留下不可見焦點。

風險：JavaScript 在 900px 切換時收合，CSS 實際在 700px 切換。701 至 900px 導覽始終可見，現有差異通常不影響使用，但統一 700px 可減少維護混淆。跨越 700px 的選單狀態可能保留，應實測旋轉螢幕。

未知：本次僅檢查程式，未操作共用瀏覽器，沒有真人可用性證據。
