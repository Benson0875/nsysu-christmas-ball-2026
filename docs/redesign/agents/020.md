# 020 贊助詢問的衡量方式

範圍：區分合作入口點擊與有效品牌詢問。

證據：檢查時 public/app.js 未見分析服務、事件收集或後端。scripts/build.mjs 依聯絡設定產生靜態入口。既有文件沒有可用的贊助轉換數據，不能聲稱已追蹤詢問成效。

建議：把合作入口點擊、實際收到訊息、有效品牌詢問、進入洽談與確認合作分開記錄。有效詢問需有可辨識品牌與具體合作需求，排除垃圾訊息及同一品牌重複聯絡。點擊率的分母使用同期間合作頁有效瀏覽，洽談比例以去重後有效詢問計算。初期可由主辦方以匿名編號人工記錄來源與階段，公開前只呈現彙總資料。

未知：目前沒有分析工具、基準樣本或品牌窗口測試。網站外連 IG 後，僅憑點擊無法證明已送訊息。正式追蹤方案需交代觀察期間、來源歸因與資料可取得範圍。
