# 019 贊助提案取得方式

範圍：讓品牌取得合作資料，同時避免把內部原稿直接公開。

證據：docs/redesign/FACTS.md 與 docs/SOURCES.md 都明確記載，不將原始品牌合作提案、私人資訊或內部檔案上傳公開網站。現有合作項目涵蓋網站、社群與現場露出，發布期間、次數與正式條件仍須確認。

建議：頁面先公開已核對的合作摘要、曝光形式與回報方式，讓品牌有足夠依據判斷是否洽談。提供官方 Instagram 私訊入口，按鈕使用「索取合作資料」，不要連到私人 PPTX。若未來需要下載版，另製作經主辦方確認的公開 PDF，移除內部備註、私人資料與未確認承諾，再加上版本日期。

未知：目前沒有已核准公開的合作 PDF，也沒有確認品牌專屬聯絡窗口與回覆時限。不可顯示假下載按鈕或承諾即時回覆。
