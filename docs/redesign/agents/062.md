# 062 手機票種與優惠理解

檢查範圍：新版 dist/visit.html 的票種、團報與系費優惠，對照使用者提供的官方 Google 表單暫存。

程式證據：頁面在報名流程前列出主辦七系學生 500 元、其他中山學生 600 元。下一段明示三人團報每人折 50 元，主辦七系已繳系學會費者再折 50 元，兩項可合併。400 元附有兩項資格，與表單一致。三人團報由一人填寫，付款規則也常駐呈現。

真人任務腳本：請其他中山學生找出單人及三人團報各需多少錢，再請已繳系費的主辦系學生算三人團報票價。記錄答案、耗時與回看段落。預期分別為 600、550、400 元，不能直接提示答案。

未知：尚無真人執行資料，不能宣稱學生都能理解。若常混淆，可補兩個計算示例，保留優惠資格。
