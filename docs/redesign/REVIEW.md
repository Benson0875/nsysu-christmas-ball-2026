## 選擇依據

比較 A 插畫與資訊並列、B 歷年照片首屏、C 大日期票券版。A 保留素材辨識並讓操作更明確，B 的真實照片放在下一區，C 的票價資訊分列用在參加頁。

這是依資料、可讀性與操作檢查選出的版本，尚未證明能提高參加意願或報名率。候選畫面由同一網站版面作受控調整，未冒充獨立上線實驗。

## 重現方式

```sh
npm run build
npm run dev
npm test
node scripts/capture-redesign.mjs
```

本次環境執行瀏覽器需在測試或截圖命令前加入 `env LD_LIBRARY_PATH=/tmp/xmas-browser-libs/root/usr/lib/x86_64-linux-gnu`。一般已安裝 Playwright 系統依賴的環境不需要。

`node scripts/capture-share.mjs` 可重製分享圖。`python3 scripts/refresh-fonts.py` 可從 Google Fonts 取得覆蓋目前來源用字的 Noto WOFF2 子集，完成後重新建置。
