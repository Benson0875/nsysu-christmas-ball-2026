# 064 手機現金繳費流程

範圍：報名頁能否讓學生辨識繳費日期、時間、地點與方式。

證據：正式表單寫明 12/1 至 12/4、12:15 至 13:00、車管會前菩提樹下，僅收現金。新版 visit.html 的常駐三步驟、按鈕下方說明與 FAQ 均一致。報名截止日 11 月 30 日與繳費日期分開呈現，沒有把填表當作完成付款。

真人任務：讓受測者在手機查看報名頁，詢問「你已填完表，接下來要在哪一天、幾點、去哪裡、帶什麼完成報名？」記錄四項答案、尋找時間與是否誤認可線上付款。不要先提示位置，也不要讓受測者真的送出資料或付款。

建議：保留按鈕附近的現金提醒。收費位置如有正式地圖可補充，現階段不可自行猜測座標。

未知：尚無真人測試，不能宣稱學生已理解或流程降低放棄率。
