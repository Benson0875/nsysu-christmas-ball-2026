# 029 案例證據交叉檢查

範圍：檢查 021 至 028 的證據可支持哪些改版判斷。

可用依據：025 直接讀取飯店官方交通頁，可核對地址與導航入口。026 直接核對使用者提供的官方表單，可支持票價、優惠、入場與付款規則。027 是原作者的方法論，可支持工作流程設計，不能支持轉換提升。

限制：021 的官方索引有跨年片段，僅借用資訊分層。022 的 KKTIX 文件屬官方流程說明，沒有特定活動畫面證據。023 未取得外部頁面內容，建議來自本專案程式。024 僅有官方索引摘要，未完成視覺檢查。028 在本次檢查時尚未產出，不列為已審查。

建議：保留各報告的取得方式與限制。案例可提供候選做法，不能聲稱已證明本活動報名率提高。先用真人任務測試檢查資訊可尋性，再以一致流量來源比較實際行為。

未知：本案沒有可比的舊版轉換基準、真人學生測試與有效贊助詢問資料。
