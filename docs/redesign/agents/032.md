# 032 歷年照片首屏方向

範圍：以真實活動照片作為首頁主視覺的候選方案。

證據：group、crowd、friends 均有 640、960、1440 寬度的 WebP。來源紀錄將照片標為 2025，無法代表本屆場地或參加規模。現有 build 以插畫為首屏，照片位於下一區。

版面：桌面採大幅 group 照片與獨立深藍文字欄，日期、活動名稱與報名按鈕放在文字欄。若需要疊字，必須使用足夠實色底襯並檢查最亮背景，不能只靠陰影。照片旁固定顯示「2025 活動紀錄」。

手機：先顯示日期、活動名稱、報名與票價入口，再顯示保留人物的橫幅照片。避免全螢幕照片把主要操作推到下方，裁切不得切掉人物臉部。照片作為首屏時不應 lazy load，依手機寬度選用 srcset。

限制：照片可傳達真實朋友互動，但目前照片中的人數不能證明規模。此方向的吸引力仍須真人五秒測試驗證，也要與插畫方案比較活動辨識度。
