# 036 歷年照片裁切與響應式

範圍：人物完整、圖片尺寸與歷史照片標示。

證據：已直接查看 group-960.webp，六人分布於畫面中央至左右邊緣。三組照片皆提供 640、960、1440 寬 WebP。group 原始比例約 1.505，crowd 與 friends 約 1.503。build 共用 photo helper 提供 srcset 與 lazy loading，但固定 sizes 為桌面 65vw，亦固定 width 1440、height 958。舊 CSS 有 group 絕對定位與長方形 cover 裁切規則，可能延續到新版。

建議：入口合照維持約 3:2 完整比例，不能手機改窄直式裁去左右人物。照片圖說固定顯示 2025 活動紀錄。不同欄位用對應 sizes，桌面小欄不需要宣稱 65vw。移除舊版 archive-large 絕對定位規則的影響，再以 375、768、1440 寬檢查人物與圖說。

未知：新版 CSS 正在修改，需待最終畫面確認。照片能證明過往現場樣貌，不能證明今年到場人數、場地或報名熱度。
