# 079 社群分享圖與 metadata 檢查

範圍：分享圖尺寸、建置引用與八頁中繼資料，未使用瀏覽器。

證據：file 確認 public/assets/share.jpg 是 1200 × 630 JPEG，約 107 KB。scripts/build.mjs 使用活動正式網址組成絕對圖片 URL。八個建置頁皆指向同一張圖，og:image:width 與 height 均為 1200、630，twitter:card 設為 summary_large_image，另有圖片替代描述。

建議：目前尺寸與引用一致，可交付。正式部署後再用實際分享預覽確認圖片可公開取得，並檢查平台快取是否更新。

未知：本次未檢查圖片內文字的視覺裁切，也未驗證 LINE、Facebook、X 等平台抓取結果。靜態 metadata 正確不代表分享點擊或報名成效提升。
