# 069 手機語言切換與報名動線

範圍：檢查建置程式與八個正式輸出頁面的語言切換及報名目的地。

證據：中文四頁分別連往 en 目錄的同名頁面，英文頁連回上一層同名中文頁。頁面 lang、切換連結 lang 與 aria-label 都隨語言正確產生。兩種語言的首頁與參加頁均使用同一個正式 HTTPS Google 表單，當晚活動頁引導至參加資訊，品牌頁維持合作動線。

建議：目前路由對應可保留。真人測試可從英文參加頁開始，切換中文後找票價，再返回英文並前往正式表單，確認使用者沒有迷路。切換語言後頁面回到頂端屬現有行為，可於測試記錄是否造成困擾。

未知：Google 表單本身的英文支援尚未確認，不能因網站提供英文就宣稱整段報名流程皆為雙語。本次為程式與輸出檢查，未模擬真人意見。
