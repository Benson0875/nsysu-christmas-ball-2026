# 071 中尺寸導覽檢查

範圍：701 至 900px 中英文導覽與選單跨斷點狀態。

證據：以獨立 Playwright Chromium 測試 701、720、768、800、900px，各自開啟中英文首頁並等候字型載入。十種組合的 document scrollWidth 均等於 viewport，導覽連結無文字溢出，右側語言控制位於邊界內。390px 開啟選單後切至 768px 再回到 390px，實測 aria-expanded 為 false。

建議：本次中尺寸導覽通過，沒有證據需要將整個桌面導覽提前折疊。根代理已將 JavaScript 斷點改為 700px，與 CSS 一致。上述測試是修改後結果。

限制：這是瀏覽器功能與版面檢查，不能證明真人能快速找到報名或願意參加。
