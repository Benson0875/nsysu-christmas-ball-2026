# 040 贊助頁資訊分組

範圍：品牌是否能快速找到受眾、合作項目與成果證據。

證據：scripts/build.mjs 已將贊助頁拆成活動規模、歷年照片、合作方式、成果回報及籌辦團隊。src/event.mjs 的 300 至 350 人有企劃預估標示，品牌名單為空時不生成 Logo 牆。public/style.css 以紙色區塊凸顯成果回報與聯絡入口。

建議：保持「活動受眾與預估規模 → 三類合作項目 → 回報資料與私訊入口」順序。將預估標籤與數字放在同一視覺群組，避免大數字脫離限制說明。歷年照片旁保留年份，不能當作人數證據。合作項目列出可交付內容，成果回報以實際可取得資料為準。

未知：沒有品牌窗口測試或有效詢問基準，分組清楚仍不能證明贊助意願提升。應請窗口找出曝光方式及聯絡入口，記錄缺漏資訊。
