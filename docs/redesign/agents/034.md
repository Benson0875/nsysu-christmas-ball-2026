# 034 插畫配色與對比

範圍：以現有插畫決定介面色彩，檢查文字對比。

證據：已查看 title-540.webp，畫面為深藍夜景、米白手繪字與暖金吊燈。現有 style.css 的色票與素材相符，可保留，不需新增漸層或玻璃卡片。

建議色票：背景 #172239，深色 #111b2e，正文 #f2eee3，次要文字 #c3c6ce，重點與按鈕 #d7bd85，紙色區 #eeebe3 搭 #243149。以 sRGB 相對亮度公式計算，正文對深藍 13.68:1，次要文字 9.28:1，暖金按鈕搭深色字 9.43:1，紙色搭深色字 10.95:1。

限制：暖金字放紙色背景僅 1.53:1，不應用於文字或重要圖示。照片與插畫上的字需獨立實測，不可套用純色對比結果。配色吻合素材不代表已證明學生參加意願提升。
