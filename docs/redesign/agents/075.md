# 075 無 JavaScript 與漸進增強

範圍：停用腳本時，導覽、報名、交通與日曆是否仍可操作。

證據：build.mjs 使用原生連結提供報名、語言切換、地圖、Instagram 與 event.ics 下載。CSS 只有在 html 存在 js 類別時才收合手機導覽。tests/site.spec.mjs 已有停用 JavaScript 的手機導覽與報名檢查。

發現：首頁分享按鈕依賴 app.js，但停用 JavaScript 時仍可見且沒有功能。這不阻擋報名，但屬於可避免的無效操作。

建議：預設隱藏分享按鈕，只在 js 類別存在時顯示，或提供可直接複製的活動網址作為備援。加入停用腳本時分享按鈕不可見的檢查即可。

未知：本次僅靜態檢查，未操作瀏覽器。無法據此判斷參加意願或報名成效。
