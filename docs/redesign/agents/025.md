# 025 官方場地交通案例

範圍：核對活動地址，研究官方交通資訊的呈現方式。

來源：[福容高雄交通位置](https://www.fullon-hotels.com.tw/kh/tw/location/)，2026 年 11 月 5 日讀取。頁尾地址為高雄市鹽埕區五福四路 45 號，與現有活動資料一致。官方頁按開車、機場與高鐵出發點分類，提供獨立導航入口。

建議：活動網站保留完整飯店名稱、芙蓉廳與地址，並列「開啟地圖」和「飯店交通資訊」。活動學生多從校園出發，首頁不必搬入所有機場與高鐵路線。將導航做成直接可按的動作，避免嵌入地圖拖慢手機載入。

限制：官方頁有歷史站名與不同出口描述，網站不應自行複製成最新路線。飯店房客免費停車不等於活動參加者免費，不能延伸宣稱。現場報到動線依主辦方公告。
