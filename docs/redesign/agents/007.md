# 007 交通與地點資訊

範圍：學生能否辨認活動場地，並取得可靠的前往方式。

證據：src/event.mjs 已有高雄福容大飯店芙蓉廳與高雄市鹽埕區五福四路 45 號。mapURL 使用完整飯店名稱的 Google Maps 查詢，venueURL 指向飯店官方交通頁。scripts/build.mjs 的參加資訊頁提供地圖與官方交通兩個入口。

建議：首頁基本資訊列出飯店名稱與廳名，參加資訊頁保留完整地址與「開啟地圖」「飯店交通資訊」。地圖入口應在手機上容易點按。測試連結是否指向高雄館，避免同名飯店造成混淆。活動時間與開放入場時間分開標示。

未知：報到位置、開放入場時間與主辦交通安排尚未確認。不得自行補上接駁、車程、捷運班距或停車優惠。若之後提供步行路線，應以實地走訪或官方資訊確認。
