# 021 官方活動網站的資訊分層

範圍：大港開唱官方網站的購票資訊與常見問題分層。

證據：[官方購票頁](https://megaportfest.com/ticket/) 將購票入口、票種與購票規則集中呈現。[官方 FAQ](https://megaportfest.com/info/faq/) 以具體問題整理入場與票券例外。搜尋可讀內容有跨年度片段，僅借用資訊組織方式，不引用其活動數字。

建議：本案首頁呈現吸引理由、日期地點與報名入口，參加資訊頁集中票價、優惠、付款與入場規則，FAQ 處理資格、服裝與特殊疑問。不能將付款規則只藏在 FAQ，因為它影響報名是否成立。

未知：上述案例不能證明本案轉換提升，也沒有可比的學生流量數據。新版仍須用真實學生任務測試檢查資訊可尋性。
