# 010 現場照片的證據界線

範圍：真實照片能否吸引學生，同時避免造成今年現場或參加規模的錯誤印象。

證據：SOURCES 與 FACTS 記載照片由活動團隊提供，屬於去年活動。group 為六位同學入口合照，crowd 為室內互動，friends 為燈串下合照。現有建置器在主要照片附歷屆說明，部分位置另外呈現 2025 年份。300 至 350 人來自本次企劃預估，無法由照片證明。

建議：照片旁直接標示「2025 活動紀錄」，讓手機讀者也能在同一畫面看見年份。照片可以傳達穿著、朋友互動與場景，不應配上暗示售罄或大批人潮的文字。保留人物完整的橫幅與適合手機的裁切，避免重複拼接同一群人造成規模錯覺。贊助頁若使用照片，明確區分歷史紀錄與本次合作規劃。

未知：照片能否增加參加意願仍需真人比較測試。原授權範圍未包含第三方自由再利用。無歷史實到總數，也沒有照片可證明本次飯店布置。
