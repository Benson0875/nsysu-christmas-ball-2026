# 015 現場品牌合作與場地限制

範圍：贊助商能否辨識現場合作內容，以及哪些安排需要先取得確認。

證據：品牌提案盤點列出投影布幕 Logo、主持介紹與商品展示，場地相關項目須先經飯店確認。現有 `partnershipWays` 已有三類曝光方式，但沒有交付次數、尺寸、位置與執行時間。使用者另提供官方 Instagram 與報名表單，可作為活動公開入口，不能當成品牌合作已確認的證據。

建議：贊助頁以「可洽談的合作項目」列出布幕標誌、主持介紹與商品展示。每項寫清楚需要雙方確認的內容。合作後的紀錄可包含實際現場照片、主持介紹紀錄與物資交付資料。未確認的攤位、試吃、販售或抽獎不得直接加入權益。

未知：飯店允許的展示位置、電力、食品與場佈規則，品牌素材規格，以及實際可執行次數。這些都須由主辦方與飯店確認，網站不能先保證。
