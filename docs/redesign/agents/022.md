# 022 票價透明度案例

範圍：票種、優惠與付款條件是否在報名前可理解。

證據：官方 Google 表單原始檔 `/tmp/xmas-form.html` 列主辦七系 500 元、非主辦七系 600 元、三人團報每人減 50 元、已繳主辦系學會費再減 50 元，優惠可合併。另列僅現場現金收費，未按期限付款視同放棄。

案例：KKTIX 官方購票流程將票價與張數確認列於填表步驟。來源 https://support.kktix.com/hc/zh-tw/articles/23055347123993-KKTIX-線上活動購票流程 。KKTIX 活動目錄直接開啟遭 403，因此未聲稱已完成特定活動畫面比較。

應用：用兩個票種清楚列原價，再獨立交代優惠資格與可合併規則，報名按鈕旁提示現金繳費流程。若顯示最低價，必須同時標示符合兩項優惠的資格，避免學生誤認人人適用。

未知：截止年份在表單中有矛盾，未確認前不能發布。退費規則與名額尚無證據，不套用其他售票平台條款。
