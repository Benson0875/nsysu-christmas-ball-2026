# 031 插畫與活動資訊並列

範圍：使用現有手繪素材，讓學生同時看見活動風格與報名資訊。

依據：現有 garden、title、castle 插畫已有深藍、暖金與象牙白色系。src/event.mjs 已更新正式報名表、500／600 元票價與團報優惠。原三聯圖放在標題之前，會延後基本資訊出現。

版面：桌面左側放日期、活動名、地點與報名按鈕，右側使用單張插畫。票價緊接主要按鈕，完整三聯圖移到展開區。手機依序為活動標示、標題、日期時間地點、票價、報名、插畫，再接 2025 活動照片。避免文字疊在細節繁多的插畫上。

優勢：沿用辨識度高的原創素材，文字可獨立縮放與維持對比。限制：插畫不能證明現場氣氛或參加規模，仍須真實照片補充。城堡插畫含舊日期，展示時必須完整遮住並提供正確日期。是否提高參加意願仍待真人測試。
