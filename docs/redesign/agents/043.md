# 043 動態效果與減少動態設定

範圍：新版頁面動態是否妨礙閱讀與報名。

證據：public/style.css 僅保留按鈕背景色 0.18 秒轉換與頁內平滑捲動。prefers-reduced-motion 為 reduce 時，捲動改為 auto，動畫與轉換全部關閉。public/app.js 不再依賴 IntersectionObserver 隱藏正文，主要操作不需等待入場動畫。

建議：維持目前靜態內容優先的設計，不增加自動輪播、視差或需要等待的片頭。瀏覽器以 reduce 設定重新測試返回頁首、主視覺展開、手機導覽與報名入口，確認操作結果不依賴動畫才能理解。保留鍵盤焦點外框。

未知：本代理完成程式檢查，未量測實際裝置掉幀，也未進行對動態敏感使用者的真人測試，不能宣稱所有人都感到舒適。
