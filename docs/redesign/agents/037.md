# 037 手機首屏高度預算

範圍：375 × 812 與 390 × 844 手機首屏的內容順序與垂直空間。

證據：新版 scripts/build.mjs 已將 hero-copy 排在 hero-art 前，順序是活動識別、主題名、兩行主標、介紹、日期時間地點、資格、報名與票價、優惠。檢查時 public/style.css 仍有舊版 hero-caption 與多輪覆寫，手機導覽最終高度 86px，正文 21px、行高 1.9。以下為靜態估計，尚無新版瀏覽器量測。

建議：扣掉 86px 導覽後，375 × 812 的首屏可用約 726px。主標約 110px、三項活動資訊約 150px、主要操作約 100px，加上識別與介紹約 130px、間距約 80px，合計約 570px，可保留基本資訊與報名入口。插畫排在後面，不強制同屏。

風險：既有大段落規則與 1.9 行高可能讓日期或按鈕掉到第二屏。請實測 375、390、320px，並檢查英文長地點與 200% 字體，不用固定高度或裁切隱藏內容來達成首屏目標。
