# 030 案例研究取捨

範圍：交叉比較 021 至 029 與目前 src/event.mjs，選擇能直接用在本案的模式。

採用一：首頁集中活動理由、日期地點與報名入口，票價頁集中價格、優惠和付款規則。021 提供資訊分層參考，026 以官方表單支持本案的實際內容。新版已接正式表單，應讓填表後仍須繳費的條件出現在入口附近。

採用二：地圖與飯店官方交通連結並列。025 已核對官方地址，此做法可提供可操作導航，同時減少網站自行維護班距與路線的負擔。

採用三：將品牌合作拆成網站、社群與現場三類，再導向官方 IG。024 提供分類參考，本案權益必須依 FACTS 中提案資料與雙方確認內容書寫，曝光數字不能沿用外部案例。

淘汰：直接套用大型音樂節的售罄、龐大人潮、保證觸及或獨家攤位等宣傳。案例規模與本活動不同，現有資料無法支持這些承諾。

限制：這些模式有事實或案例依據，尚無真人測試與可比轉換資料。029 未及檢查的 028 已產出，屬文案判斷而非成效證明。
