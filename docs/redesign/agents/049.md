# 049 票價與合併優惠文案核對

範圍：基本票價、三人團報與系學會費優惠。

證據：使用者提供的正式報名表確認主辦七系學生 500 元，非主辦七系學生 600 元。三人團報每人折 50 元，主辦七系已繳系學會費者再折 50 元，兩項可合併。src/event.mjs 的價格與優惠敘述一致。

建議保留兩列原價及各自適用對象。優惠內文可精簡為「三人團報每人折 50 元。主辦七系已繳系學會費者再折 50 元，兩項可合併。」若顯示 400 元，緊鄰標示「主辦七系、已繳系學會費且三人團報」，避免被讀成所有人的價格。非主辦七系三人團報為每人 550 元，不應套用系費優惠。

未知：無付款或報名完成統計，無法證明優惠文案帶來轉換提升。需真人票價判讀測試。
