# 078 分享能力不足與剪貼簿拒絕覆核

範圍：僅靜態檢查 public/app.js 與 tests/site.spec.mjs，未重跑測試。

證據：沒有原生分享時改用剪貼簿。剪貼簿拒絕會進入錯誤處理，顯示手動複製瀏覽器網址的提示。能力皆缺少時同樣顯示失敗提示，取消分享則使用獨立訊息，不發出 share_complete。

修復後覆核：測試已涵蓋剪貼簿成功、NotAllowedError 拒絕、原生分享取消與無 JavaScript 隱藏分享按鈕。新增的拒絕測試符合目前處理方式。

剩餘限制：能力皆缺少的分支尚未見獨立測試，真實裝置的分享面板仍需人工確認。沒有發現阻擋問題。分享完成事件不能證明朋友收到網址或完成報名。
