# 052 贊助權益的承諾界線

範圍：檢查合作項目是否把可洽談內容寫成保證。

證據：src/event.mjs 已把三類合作寫為網站、社群與現場，並在 partnershipBody 明列曝光位置、次數與執行內容依雙方確認。社群內容和時程同樣須確認，現場用「可討論」，沒有保證觸及或轉換。300 至 350 人標為企劃預估，未冒充報名數。

建議：保留這些限定語，避免後續文案改成「必定觸及」或「保證到場」。現場段落可補「依場地規範確認」，讓商品展示與場地許可一致。結案回報維持依約提供且限可取得資料，不能暗示每個方案都包含全部數據。

未知：正式合作品牌、刊登次數、執行期間與場地許可尚無確認資料。這份檢查只證明文案承諾較清楚，不能證明品牌會願意贊助。
