# 012 贊助受眾與主辦可信度

範圍：贊助頁如何交代學生受眾與籌辦團隊，避免誤示校方背書。

證據：FACTS.md 依提案第 3、5 頁確認開放國立中山大學各科系學生參加，由七系與學程學生籌辦。沒有逐一證明所有列名領域均隸屬中山大學，也沒有校方正式主辦或授權背書的資料。

建議：使用「開放中山各科系學生參加」說明對象，以「七系與學程學生籌辦」說明執行團隊。合作頁分開列受眾、籌辦者與曝光方式，避免把學校名稱、Logo 或系所名單排成正式校方贊助或背書。可信度應補足可核對的團隊公開聯絡方式、既有活動紀錄與執行回報方式。

未知：學生年級與科系分布、實到比例、各籌辦單位正式名稱與品牌使用許可尚未證實。不得自行補出受眾占比或宣稱全校官方活動。
