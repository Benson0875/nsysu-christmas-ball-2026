# 童話序曲，聖誕舞章

國立中山大學 2026 七系聯合耶誕晚會活動網站。

**活動網站：[童話序曲，聖誕舞章](https://benson0875.github.io/nsysu-christmas-ball-2026/)**

[English website](https://benson0875.github.io/nsysu-christmas-ball-2026/en/)

2026 年 12 月 24 日，18:00 至 21:00，於高雄福容大飯店芙蓉廳舉行。網站目前為活動前資訊頁，報名尚未開放。

首頁、當晚活動、參加資訊與合作品牌共四頁，提供完整繁體中文及英文版本。首頁以三張原創插畫連成全景，手機可左右滑動。去年照片明確標示為歷屆紀錄。

首頁最下方支援品牌 Banner，合作品牌頁支援 Logo、簡介與官方連結。尚無正式合作品牌時不顯示假名單。

## 本機預覽

```sh
npm ci
npm run build
npm run dev
```

開啟 http://127.0.0.1:4173/nsysu-christmas-ball-2026/ 。
