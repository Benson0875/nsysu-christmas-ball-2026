# 076 URL 與部署路徑檢查

範圍：八頁的相對連結、資源、雙語路由與社群網址。

證據：建置器以相對檔名連接同語言頁，英文資源使用 ../ 前綴。canonical、hreflang、OG 圖片與 sitemap 以正式 siteURL 產生，包含 GitHub Pages 專案子路徑。公開外連經 safeURL 限制 HTTPS，合作素材檔名亦有驗證。使用 HTMLParser 逐一檢查 dist 八頁的 href 與 src，相對目的檔全部存在。

判斷：未發現基底路徑或資源遺失問題。報名表、IG、地圖及飯店連結在設定端驗證，內部票價錨點使用 visit.html#prices。

界線：檔案存在不能證明正式部署已更新，也不能保證外部服務持續可用。發布後仍需由正式網址走過中英文頁、報名及贊助入口。
