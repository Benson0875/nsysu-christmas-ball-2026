# 063 手機開啟表單與返回

範圍：報名外連與返回活動頁的流程。

證據：src/event.mjs 指向使用者提供的 HTTPS Google 表單。scripts/build.mjs 的報名按鈕是原生連結，沒有 target，會在原分頁開啟，因此沒有新分頁 opener 風險，也不依賴 JavaScript 才能使用。公開連結有 HTTPS 檢查。app.js 只送出頁內互動事件，不會提交表單。

測試：手機點擊報名，確認目的網域與表單標題。不要填寫或送出資料，使用瀏覽器返回，確認可回到活動頁並找到票價與付款說明。若表單發生登入或網路錯誤，返回後仍應保有資訊入口。

建議：按鈕旁以短文字識別 Google 表單，避免預期誤差。未知：表單外部頁面、登入條件與手機返回位置需真實裝置測試，本站點擊事件不能證明完成報名。
