# 041 票價與優惠視覺

範圍：票價卡片與優惠條件是否容易比較。

證據：正式表單列主辦七系 500 元、其他中山學生 600 元。三人團報每人折 50 元，主辦七系已繳系費者再折 50 元，優惠可合併。新版 prices 區已用兩張卡片分列原價，discount 區說明條件。

建議：保留兩個完整原價，不用 400 元起當主標。優惠區將團報資格與系費資格拆成短句，400 元旁維持兩項條件。報名入口附近直接顯示現金繳費日期與地點，讓學生理解填表後還有付款步驟。手機以單欄卡片避免條件擠在價格旁。

未知：系費資格是否會在表單中驗證，及不同系所混合團報的操作方式尚未實測。不能自行新增限制。截止日期年份矛盾仍待主辦確認。
