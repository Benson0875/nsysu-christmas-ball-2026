# 033 大日期票券版

範圍：以日期與報名資訊為視覺核心的候選方向 C。

依據：正式報名表已提供 500／600 元票價、三人團報優惠與 17:45 至 18:15 入場時段。現有深藍、暖金、象牙白與本機字型可延用，無需新增裝飾素材。

版面：桌面把 12.24 作為大型字樣，旁列活動名稱、18:00 至 21:00、福容芙蓉廳與報名按鈕。下方使用票券形式分列兩種價格，優惠另列資格，避免把 400 元當成所有人適用的起價。插畫縮為頁角或第二區。手機依序為活動名稱、日期地點、票價與報名，文字保持實際 DOM，不烘進圖片。

比較：A 插畫並列較能保留活動辨識，B 歷年照片較能呈現真實互動，C 方便掃讀與比較票價。C 可能缺乏活動氣氛，且大日期若佔滿手機首屏仍會遮蔽操作。建議 C 作為資訊排版備選，不能僅憑設計偏好宣稱優於 A/B，需五秒辨識與報名任務測試。
