# 023 手機活動導覽案例

範圍：活動網站的手機導覽與報名動線。

來源：嘗試讀取大港開唱官方網站 https://megaportfest.com/，網頁工具未取得可讀內容，因此沒有把該站的手機版型當成已觀察證據。

可查證基準：本專案 scripts/build.mjs 有首頁、當晚活動、參加資訊、合作品牌四條路徑，導覽以按鈕搭配 aria-expanded 控制。現有結構可保留，不需要為了改版增加更多分頁。

建議：手機選單用學生看得懂的名稱，保留活動內容、票價與報名、贊助合作入口。報名按鈕在首屏和參加頁都可找到，外部表單前先說明票價與付款方式。公開資訊與贊助資訊分流，避免學生為了找票價進入合作頁。

限制：這是根據既有程式與任務需求的設計建議，尚無外部案例手機畫面或真人任務測試支持。後續應測量學生找入口的時間與成功率。
