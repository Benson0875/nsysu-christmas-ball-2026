# 038 桌面首屏比例與行動優先序

範圍：桌面首屏的文字、插畫、報名入口與照片尺度。

證據：新版 `.hero` 使用 1.05fr 與 1fr 雙欄，最大內容寬度 1280px，插畫上限 650px。文字欄包含主標、日期、時間、地點、對象與兩個操作。主要報名按鈕採暖金實心，票價入口採文字連結，優先序明確。歷年照片在下一區，主圖比例 1.5，小圖 1.15。

建議：桌面維持雙欄，測試 1280×720 與 1440×900 時報名按鈕是否位於首屏。若高度不足，先縮短主標上下留白，不縮小資訊字級。歷年合照保留橫向比例與年份圖說，小圖裁切需確認人物臉部完整。大螢幕維持 1280px 上限，可防止文字與插畫過度分離。

未知：本報告為樣式與結構檢查，未執行瀏覽器截圖。首屏可見性及照片裁切仍須實際驗證，不能據此宣稱參加意願提升。
