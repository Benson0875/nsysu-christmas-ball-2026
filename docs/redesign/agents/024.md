# 024 贊助權益案例

範圍：官方大型活動如何把合作方式寫成可討論的項目。

來源：[SXSW 官方合作頁](https://sxsw.com/marketing/) 與 [官方品牌活動說明](https://explore.sxsw.com/activations)。本次讀取搜尋索引摘要，原 sponsorship 網址無法開啟，未完成頁面視覺檢查。

觀察：官方依品牌活動、客製活動、合作節目與場地配置區分合作機會，描述品牌能做什麼，再引導聯絡討論。

應用：本活動可依提案現有依據列出網站 Banner 與 Logo、社群貼文與限動、布幕 Logo 與主持介紹，並用官方 IG 洽談。每項交代展示位置與需雙方確認的內容，比單純寫「提升曝光」更具體。

限制：大型節慶的規模、流量與案例不能移植為本活動成效。未知刊登期間、發布次數、現場設施與報價，不能自行保證。
