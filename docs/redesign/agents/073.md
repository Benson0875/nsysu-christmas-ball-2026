# 073 圖片載入與尺寸

範圍：scripts/build.mjs 圖片標記與 public/assets 檔案。

證據：首屏 garden 提供 540w 與 900w WebP，設 fetchpriority high，未設 lazy。歷年照片提供 640w、960w、1440w，使用 lazy 與 async 解碼。圖片有 width、height 預留比例。WebP 單張約 23 至 165KB，首屏最大插畫約 99KB。折疊主視覺使用 lazy。

建議：維持首屏優先與下方延遲載入。photo helper 的桌面 sizes 統一 65vw，對較窄的 archive-small 會高估，日後可依欄寬傳入 sizes，降低多取大圖機會。group 1440 實際高 957，標記 958 差異僅一像素，無阻擋性問題。
