# 068 手機入場資訊查找

範圍：檢查入場時間是否只能在 FAQ 找到。

證據：`dist/visit.html` 在常駐報名步驟「當天入場」已列 12/24、17:45 至 18:15 入場與 18:00 開始。FAQ 再補充相同資訊。`src/event.mjs` 的當晚活動頁也直接顯示入場時段，因此重要資訊沒有只藏在收合問答。

建議：維持常駐報名步驟，讓 FAQ 處理再次確認。手機真人任務可問「你打算幾點到現場，在哪裡找到這項資訊」，記錄尋找時間、是否誤把 18:00 當入場開始、是否需要展開 FAQ。

未知：尚無真人測試結果，不能由程式碼結構判定學生一定找得到。逾時入場與報到位置仍須正式公告，不自行補規則。
