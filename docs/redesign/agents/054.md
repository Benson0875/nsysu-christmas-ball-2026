# 054 導覽與行動文字檢查

範圍：導覽、報名與合作按鈕是否說清楚目的地。

證據：`src/event.mjs` 使用「票價與報名」「填寫報名表」「查看票價」「私訊洽談贊助」。`scripts/build.mjs` 的報名按鈕指向正式 Google Forms，票價連結指向參加頁 `#prices`，合作按鈕指向官方 Instagram。名稱與實際操作一致，英文 Open registration form 亦明確。

建議：保留目前直接的動詞。報名按鈕附近可補「前往 Google 表單」，讓外部跳轉更可預期。當晚活動頁的「查看票價」目前指向參加頁頂端，若要精準一致可加上 `#prices`。不需要新增抽象口號或改成「立即搶票」。

未知：實際點擊理解程度仍需學生操作測試。外連點擊不代表送出表單或完成付款。
