# 008 服裝、禮物與報到疑問

範圍：檢查參加前的準備資訊，避免把活動時間誤認為報到時間。

證據：src/event.mjs 已確認活動 18:00 至 21:00，但報到時間與開放入場時間未公布。FAQ 將服裝與禮物合併成一題，回答目前尚未公布。docs/SOURCES.md 同樣列出這些資料缺口。scripts/build.mjs 使用原生 details 顯示問題，可在沒有 JavaScript 時閱讀。

建議：參加資訊頁保留簡短的「入場時間」「穿什麼」「要帶什麼」問答。回答只陳述目前公告狀態，不能暗示一定要穿正式服裝或準備交換禮物。18:00 明確標為活動開始時間。主辦確認規則後，集中更新原始資料，並同步檢查中英文。

未知：服裝要求、攜帶證件、是否交換禮物、報到位置、是否允許中途入場，均未取得正式規則。這些疑問是否實際影響報名，需要真實學生訪談或測試確認。
